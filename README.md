This project explores the use of deep learning to predict stock closing prices. Historical market data is preprocessed and transformed into sequences suitable for a convolutional neural network (CNN), which is then trained to identify temporal patterns and trends. The model’s predictions are evaluated against actual price movements, showcasing the application of machine learning techniques to financial time series forecasting.

Tools:
  - Python
  - NumPy, Pandas – Data handling & preprocessing
  - Matplotlib – Visualization
  - TensorFlow / Keras – CNN model building and training
  - Jupyter Notebook – Experimentation and analysis
